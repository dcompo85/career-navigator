# Career Navigator

A general career exploration and job-search framework for use in your own ChatGPT Project. Explore possible directions, evaluate opportunities, and prepare truthful applications and interviews.

## Start here

1. Read [the setup guide](00_START_HERE.md).
2. Copy [the project instructions](01_PROJECT_INSTRUCTIONS.md) into your own project instructions.
3. Add reference files 02 through 06 to your project.
4. Upload your resume or describe your history, then ask: **Help me work out my next career step. Start with the intake and ask a couple of questions at a time.**

Each person uses their own project and personal information. Download the repository ZIP to get the files without using Git.

## Three starting routes

- **Advance:** pursue stronger opportunities in similar work.
- **Transition:** explore a different function or industry.
- **Explore:** identify and test directions when you are unsure.

An immediate-help route supports an application or interview deadline without requiring the complete intake first.

## Design principles

Support different occupations, countries, and career stages. Separate enjoyment from readiness. Recognize transferable experience without inventing qualifications. Show unknowns and dealbreakers explicitly. Test paths with small practical experiments before recommending major commitments.

## Status

Version 1.0. Structure and scoring calculations have been checked. Independent end-to-end agent testing and real-user feedback are still pending. Scores are decision aids, not validated assessments or hiring predictions.

This is an instructions-and-templates repository. It is not an installed plugin, a hosted app, or a background job-search service. Account features and available tools vary.

## Personal information

Keep completed career briefs, resumes, contact information, and application records in your own private workspace. This repository contains general guidance, blank templates, and fictional test inputs only. The ignore rules offer limited protection against accidental commits; review every change before publishing.
