# Career Navigator
Version 1.0 • October 28, 2026

A personal framework for deciding what comes next and taking practical steps toward it. Designed for different occupations, industries, countries, and career stages. No prior resume or fixed career goal required.

## Set up your own copy

1. Unzip this package and create a separate ChatGPT Project for your search.
2. Paste the contents of `01_PROJECT_INSTRUCTIONS.md` into that project's instructions.
3. Add files 02 through 06 as project reference files. Keep this guide for yourself.
4. Add your current resume if you have one. You can remove contact details you do not need for the work. Otherwise, describe your work, education, projects, or other relevant experience.
5. Send: **“Help me work out my next career step. Start with the intake and ask a couple of questions at a time.”**

If your interface does not support project instructions, paste file 01 at the start of a new conversation and attach the reference files. Interface features and account limits may vary. This package is a set of instructions and templates, not an installed plugin or a standalone service.

Each person should use their own copy and information. Do not upload another person's completed profile or resume as a shared reference. The package contains no real candidate examples.

## Choose where to start

| Route | Starter prompt |
| --- | --- |
| Advance | Help me find a stronger opportunity in similar work. |
| Transition | Help me explore moving into a different field or function. |
| Explore | I am unsure what I want next. Help me identify and test possible directions. |
| Immediate need | I have an interview or application deadline. Help with that first and fill in the intake later. |

## What you should receive

A career brief you can correct; up to three plausible paths if you want exploration; transparent career-path and job evaluations; a manageable action plan; and truthful application or interview materials when useful.

Keep a dated copy of your career brief after meaningful decisions. At a new session, provide the latest brief if it is not already available. The package does not guarantee memory, saved updates, live job searches, background monitoring, or automated applications. Ask for an export when needed and retain it yourself if saving is unavailable.

## Package contents

- 01: Instructions to paste into your project.
- 02: Conversational intake and routing guidance.
- 03: Both rubrics, scoring anchors, and unknown-information rules.
- 04: Blank career brief, evidence, comparison, and activity templates.
- 05: Path exploration, applications, interviews, and review workflows.
- 06: Fictional acceptance scenarios and a maintainer review checklist.

The scoring weights are design defaults, not validated assessments or hiring predictions. Treat recommendations as working hypotheses and test them against your own experience.
